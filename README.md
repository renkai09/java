# FoodApp

An Android application built with Java.

## Overview
FoodApp is a native Android application (namespace: `com.example.foodapp`). It leverages modern Android UI components, including Flexbox, Material Design, and ConstraintLayout, targeting Android API level 35.

## Features
* Native Android app development using Java 11.
* Responsive UI components with Flexbox and Material Design.
* Minimal SDK support down to Android 7.0 (API level 24).

## Build Instructions
This project uses Gradle for building. Open the project in Android Studio, or use the Gradle wrapper from the command line:

```bash
# To build the project
./gradlew build

# To run the app on a connected device or emulator
./gradlew installDebug
```
